# Telepatia (Aviso Gerencial)

Use para notificar a gerente Dona Cris sobre problemas, dúvidas de clientes que você não sabe responder, ou clientes que exigem atendimento humano imediato.

## Comando

```bash
node ~/.openclaw/workspace/skills/telepatia/telepatia.js "Cliente Maria do número +5511... quer falar com você urgente sobre a bolsa Prada."
```
