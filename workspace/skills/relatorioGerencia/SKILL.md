# Relatório Gerencial

Use esta habilidade exclusivamente quando a gerente Dona Cris solicitar um relatório, resumo das vendas do dia, andamento da loja ou perguntar o status das reservas/pagamentos.

## Comando

```bash
node ~/.openclaw/workspace/skills/relatorioGerencia/relatorioGerencia.js
```

## Resposta

O script retornará um relatório consolidado e formatado por escrito. Use as informações retornadas para responder à Dona Cris de forma carinhosa, organizada e clara.
