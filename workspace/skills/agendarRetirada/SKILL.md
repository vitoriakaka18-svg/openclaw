# Agendar Retirada

Use quando a cliente confirmar que vai retirar a peça na loja e informar o dia e horário aproximado.

## Comando

```bash
node ~/.openclaw/workspace/skills/agendarRetirada/agendarRetirada.js '{"nome": "Joana", "dataHora": "Amanhã às 14h"}'
```
